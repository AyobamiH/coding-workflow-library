# v0.2.1 Release Notes

`v0.2.1` packages the evidence-backed engineering foundations added after the `v0.2.0` autonomy-model release.

## What Changed

- Added reproducible workflow-corpus extraction with source accounting, privacy redaction, deterministic output, and aggregate-only public reporting.
- Added `docs-list` for deterministic documentation discovery, title checks, duplicate detection, and explicit orphan rules.
- Added `repo-map` and `project-kb` for source-only repository orientation and reusable project memory without reading secrets or calling external services.
- Added a managed pre-commit validation gate with staged secret-pattern checks, exact-file safety, and optional local hook installation.
- Added source-only migration review with deterministic risk classifications for destructive SQL, RLS, grants, functions, triggers, pg_cron, pg_net, Vault references, and secret-shaped material.
- Hardened interrupted-run recovery so agents prefer local checkpoint, Git, lane-state, and repository evidence over stale prompt reconstruction.
- Added Opstruth product-video truth guardrails that anchor creative claims to project-owned source, current product evidence, and portable HyperFrames skill selection.

## CLI Examples

```bash
coding-workflow docs-list --validate
coding-workflow repo-map --repo /path/to/repo --validate
coding-workflow project-kb --repo /path/to/repo --validate
coding-workflow migration-review --repo /path/to/repo --validate
coding-workflow validate
```

## Safety Boundaries

The package remains permission-gated. Local inspection and validation do not grant GitHub mutation, registry publication, deployment, database writes, secret mutation, or destructive actions. Product-video truth checks do not render, publish, deploy, or call production services by themselves.

## Distribution
