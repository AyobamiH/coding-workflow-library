# v0.2.3 Release Notes

`v0.2.3` matures the library's evidence, review, portability, and release-control foundations.

## Added

- Bounded browser live proof with responsive layout, accessibility-count, console/network, viewport, redirect, and decoded PNG-content evidence.
- Read-only GitHub deep review for unresolved threads, current review decisions, stale approvals, exact patch scope, checks, and bounded failed-log categories.
- A deterministic OpsTruth classifier that keeps verified, warning, failed, skipped, and not-verified claims distinct.
- Content-derived private workflow-corpus snapshots and safe baseline comparison without publishing corpus data or local paths.
- A focused Linux, macOS, and Windows portability contract in GitHub Actions.

## Hardened

- npm package readiness and release preflight now emit validated reports, precise blockers, safe pack-manifest evidence, and optional aggregate-only corpus signals.
- Browser screenshots distinguish valid capture from nonblank content, cross-origin redirects remain warnings, and requested viewport mismatches are visible.
- GitHub branch-protection 404s remain unavailable metadata instead of being treated as proof that protection is absent.
- Skill routing descriptions and duplicate triggers were sharpened while reviewed long-form safety exceptions remain visible to `skill-cleaner`.
- Capability adapters remain below existing workflow contracts; generic brokering, prefetch, automatic installation, and bulk cutover remain deferred.

## Release Workflow

The release objective is `release-coding-workflow-library-v0.2.3`. The generic semver route requires matching package and lockfile versions, this release note, local validation, package smoke, exact-commit CI, an annotated tag, npm publication verification, and GitHub Release verification. The real lane-scoped route executes those authorized publication stages itself and can safely resume by verifying artifacts that already exist.

No application or infrastructure deployment target is declared by this package. Deployment is therefore `NOT_APPLICABLE`; npm publication is the package distribution action.

## Verification

```bash
npm test
npm run test:portable
./scripts/route-audit
./scripts/skill-cleaner
./scripts/validate-skills
./scripts/npm-package-readiness --repo . --expect-package --expect-cli --allow-pack-dry-run
./scripts/release-preflight --repo . --mode cli --allow-pack-dry-run
npm pack --dry-run --json
```

External mutations remain objective-authority gated. This release does not grant force push, history rewrite, secret mutation, or product deployment authority.
