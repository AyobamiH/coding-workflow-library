# v0.2.2 Release Notes

`v0.2.2` is a portability and privacy patch for the public workflow library.

## Fixed

- Replaced maintainer-specific absolute home-directory paths in current package content with semantic placeholders.
- Changed `run-next` to default to the caller's current working directory instead of a product repository.
- Derived env, temp, and npm cache paths from portable runtime defaults with explicit environment overrides.
- Generalized Linux, macOS, and Windows user-home path redaction in source-only helpers.
- Added a deterministic public-path gate to tests and pre-commit validation.

## Runtime Overrides

- `CODING_WORKFLOW_HOME`
- `CODING_WORKFLOW_ENV_FILE`
- `CODING_WORKFLOW_TMPDIR`
- `CODING_WORKFLOW_NPM_CACHE`

## Verification

```bash
npm test
npm run check:paths
npm pack --dry-run --json
```

The path checker reports only file, line, and category. It does not echo matched private paths.

## Historical Boundary

Previously published package versions and existing Git history are immutable evidence. This patch sanitizes the current source and package surface without rewriting history or unpublishing an older version. Consumers should use `0.2.2` or later.
